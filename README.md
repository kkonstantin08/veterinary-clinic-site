# Veterinary Clinic Site

Лендинг для Mixlab с акцентом на презентацию сервиса доставки ветеринарных препаратов.

## Стек

- HTML
- CSS
- Bootstrap
- JavaScript

## Что есть в проекте

- стартовый экран с основным оффером;
- блок с преимуществами сервиса;
- секция `How it works`;
- блок для ветеринаров;
- слайдер с отзывами;
- блоговый блок `In the Wild`;
- футер с контактами.

## Запуск

Проект статический, поэтому достаточно открыть [index.html](./index.html) в браузере.

Для локальной проверки удобнее использовать Live Server или любой простой статический сервер.

## Обновления

- добавлена мобильная адаптация для основных секций сайта;
- убраны проблемные переполнения по ширине на мобильных экранах;
- навигация в шапке теперь работает через плавную прокрутку к нужным секциям.
